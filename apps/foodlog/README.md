# Foodlog: intended use

Foods holds the catalog. Today logs from it.

## Once

1. Foods › Catalog file › Import catalog JSON.
2. Per food eaten often, in Foods:
   - ★ Add to favourites.
   - Edit › Add portion, e.g. `1 slice` · `35` g.
3. Settings › Daily targets, Meals.

## Each meal

| Step | Taps |
|---|---|
| Today › Add to *meal* | 1 |
| **+** on a food: logs the amount shown | 1 per food |
| Food name › amount › Add to *meal* | 2 per food |
| Done | 1 |

- Search: tap it, the last query is selected, type the next food.
- Keyboard: type, Enter, amount, Enter.
- Summary line: what the meal holds. Tap an item to edit or remove it.
- Undo: in the toast after each add.

## List order

1. Eaten in this meal, latest first.
2. ★ favourites.
3. Most logged.
4. With a search: name starts with it › a word starts with it › any match.
5. Name.

Only days before the logged day count, so rows stay put while adding.

## Amount on +

1. Latest amount in this meal.
2. Latest amount in any meal, same unit.
3. First portion.
4. 100 g, 100 ml or 1 portion.

## Other paths

- Copy a meal…: a whole meal from the last 14 days.
- Import day file…: a day written outside the app.
- New food… in the add sheet: a food missing from Foods.
- Foods › food › Log this food: one food, then the sheet closes.
