    Using H10 alongside Polar

    Wear the strap and enable “2 receiving BLE devices” in Polar Beat, or “2 Bluetooth devices” in Flow’s sensor settings. Start Polar’s recording, then connect here. Keep this app visible during the ride; check that Polar continues recording on your phone.

    H10 uses an HTTPS page in Android Chrome. The downloaded file supports manual HR. Live samples are processed on this device. Saved ride summaries are included in backups.
