# Check-in: intended use

Today holds everything. Every tap saves.

## Once

1. Settings › Tracked items: rename, hide or archive the default symptoms.
2. Add symptom: one per thing you want to follow.
3. Settings › Check-in timing: the day change time and how long one check-in
   stays open.

## Each check-in

| Task | Taps |
|---|---|
| Mood only | 1 |
| Mood and a mild symptom | 2 |
| One severe symptom | 3 |
| Mood and a moderate symptom | 3 |
| Add a note | 2 plus typing |

- Symptom taps: mild › moderate › severe › off.
- Tapping the chosen mood again clears it.
- Undo: in the toast after each tap.

## One sitting

Taps within 30 minutes of a check-in's start update it. The line above the
mood row says which check-in is open and until when. After that, the next tap
starts a new check-in.
